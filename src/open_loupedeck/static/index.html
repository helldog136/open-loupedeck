Editing

Page

Select a control

Choose an action from the list, then set fields. Optional label, icon URI (Simple Icons, Lucide, …), or image file — text draws on top. If both icon and image are set, the image wins on the device. Colors: #rrggbb or CSS names. Touch keys are per page; strips and side buttons use global_buttons. Encoders are not edited here — click a dial in the deck to set its dial pages (push cycles page; turn runs left/right actions).

Advanced: full action JSON

With this section open, editing the JSON overrides the form on Apply to key (must include "type"). If you only open it to read, Apply still uses the form. Media Browse… updates both the form and this JSON so paths are not dropped.
