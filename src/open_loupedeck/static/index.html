Spotify OAuth & playback — optional

Create an app (Web API). Add the redirect URI below to the app’s settings, paste your Client ID, save, then connect. Playback control needs Spotify Premium for most users, and an active Spotify Connect device (app open on phone, desktop, or web).

Logging level — applies after save (no restart)

Written to logging.level. If the agent was started with -v, root handlers stay at DEBUG until restart. Console/file toggles are only in YAML for now.

OBS Studio WebSocket server — scenes, mute, volume

OBS: Tools → WebSocket Server Settings (or Settings → Network on OBS 28+) → Enable WebSocket server → Show Connect Info for the password.

Home Assistant REST API (long-lived token) — lights, scripts, sensors, weather

In Home Assistant: your profile (bottom-left) → Security → Long-Lived Access Tokens → Create Token. Paste it below along with the base URL (e.g. http://homeassistant.local:8123). Then use the ha.* actions and display.ha_sensor / display.ha_weather on your buttons.

Twitch Helix (stream status) & multi-account actions

Configure one or more Twitch app credentials. Display keys (like display.twitch_live) use an app token. Any action whose type starts with twitch. will run once per configured account.

Editing

Page

Select a control

Choose an action from the list, then set fields. Optional label, icon URI (Simple Icons, Lucide, …), or image file — text draws on top. If both icon and image are set, the image wins on the device. Colors: #rrggbb or CSS names. Touch keys are per page; strips and side buttons use global_buttons. Encoders are not edited here — click a dial in the deck to set its dial pages (push cycles page; turn runs left/right actions).

Advanced: full action JSON

With this section open, editing the JSON overrides the form on Apply to key (must include "type"). If you only open it to read, Apply still uses the form. Media Browse… updates both the form and this JSON so paths are not dropped.
